# Backend API
Backend API built with Node.js, Express.js, and MongoDB.

## Development Plan
The backend will be developed in 3 main parts:

### 1. User API
- Create user
- Get users
- Get user by ID
- Update user
- Delete user

### 2. Shop API
- Create shop
- Get shops
- Get shop by ID
- Update shop
- Delete shop

### 3. Login Authentication
- User registration
- User login
- Password hashing
- JWT authentication
- Protected routes
- Logout

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
